# Actual Java game captures

Captured on 2026-10-28 from the actual `Board` in presentation mode, with a 1000×625 client area. The application was instantiated normally; its original start button was activated to advance through the introduction, and its first character button was activated to demonstrate exclusion.

- `game-title.png`: original title screen.
- `game-board.png`: live 24-card game board after the introduction.
- `game-selection.png`: the same board after one original card action.

Images were exported from the live Swing content using `printAll`, without compositing, replacing artwork or drawing a mock interface. They omit OS window chrome. Random character selection means later runs may display different characters.

These captures show application rendering and real game-state changes. They do not establish that a gesture, camera, Arduino or projector was used during capture. No hardware photograph or video was fabricated. No physical camera or serial port was opened for this capture.
